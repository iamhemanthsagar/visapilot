# VisaPilot

Frontend foundation for VisaPilot. This repository currently contains only a React, TypeScript, Vite, and React Router application shell.

## Requirements

- Node.js 20 or later
- npm 10 or later

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Structure

The `src` directory includes reserved domain folders for future product work. They are intentionally empty at this stage; no backend, authentication, document processing, or AI integration is included.
